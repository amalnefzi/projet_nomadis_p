## 🚀 COMMENT DÉMARRER (3 steps)

### ÉTAPE 1: Configuration initiale (UNE SEULE FOIS)

Ouvrir `cmd` dans `C:\Users\asus\Desktop\Projet_Nomadis\optimisation_tournee_api`:

```cmd
python setup_ia.py
```

Cela va:
- ✅ Installer les dépendances Python
- ✅ Vérifier MySQL et la base dist_utic
- ✅ Entraîner l'IA avec les vrais données
- ✅ Générer le modèle modele_nomadis.pkl

### ÉTAPE 2: Lancer 3 services (chacun dans un terminal séparé)

**Terminal 1 (Ouvrir `cmd` dans optimisation_tournee_api):**
```cmd
node server.js
```
Il affichera: `🚀 Serveur API prêt sur http://localhost:5000`

**Terminal 2 (Ouvrir `cmd` dans optimisation_tournee_api):**
```cmd
python api_ia.py
```
Il affichera: `Running on http://127.0.0.1:5001`

**Terminal 3 (Ouvrir `cmd` dans optimisation_tournee_front):**
```cmd
npm run dev
```
Il affichera: `http://localhost:5173/`

### ÉTAPE 3: Ouvrir l'interface

Aller sur: **http://localhost:5173**
